    Python SDK

    Connect your Python applications and AI agents to AgentGuard AI.

    v0.1.0

    Installation

    Install the locally built SDK wheel from your project distribution folder:

    python -m pip install dist\agentguard_ai-0.1.0-py3-none-any.whl

    Authentication

    Set your API key as an environment variable. Never hardcode it into your source code.

    $env:AGENTGUARD_API_KEY = "YOUR_AGENTGUARD_API_KEY"

    Quick Start

    import os
from agentguard import AgentGuardClient, AgentGuardError

client = AgentGuardClient(
    api_key=os.environ["AGENTGUARD_API_KEY"]
)

transaction = {
    "transaction_id": "agentguard-demo-001",
    "amount": 0.1,
    "network": "ethereum",
    "recipient_address": "0x1234567890abcdef1234567890abcdef12345678",
    "recipient_known": True,
    "new_contract": False
}

try:
    result = client.inspect(transaction)
    print("Gateway:", result["gateway_status"])
    print("Decision:", result["security_report"]["decision"])
    print("Risk score:", result["security_report"]["risk_score"])
except AgentGuardError as error:
    print("AgentGuard error:", error)

    The SDK is inspection-only. It does not sign or broadcast blockchain transactions. A PERMITTED decision does not authorize real transaction execution.

    Available developer gateway endpoints.

    POST /agent/inspect

    Submit a proposed transaction for authenticated security inspection.

    Authentication: X-API-Key header

    Create a developer API key for your authenticated account.

    Session authentication and CSRF protection required.
    GET /developer/api-keys

    Retrieve your API key metadata, status and last-used timestamps.

    Session authentication required.
    DELETE /developer/api-keys/{key_id}

    Revoke an API key belonging to your account.

    Session authentication and CSRF protection required.
